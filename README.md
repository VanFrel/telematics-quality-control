# Телематика бортовых систем в системе менеджмента качества автомобилей. Выявление актуальных факторов дефектов и дифференциация статистической и технологической значимости

## И. П. Фрелих, В. Г. Мосин

### Аннотация
Исследован массив эксплуатационных данных по 11 345 автомобилям с обращениями по симптому «шум в салоне на скорости 60–80 км/ч». Анализ причин дефекта объединяет таблицы сопряжённости (критерий Пирсона, коэффициент Крамера), критерий Манна–Уитни и стандартизованную величину эффекта. Показано, что на больших массивах телематики статистически значимый сдвиг параметра не обязательно значим технологически. Сдвиг медианы пробега составил лишь +416,5 км, а сдвиг медианы температуры −0,10 °C, что не превышает погрешности штатных датчиков. Главный фактор — конструкция модели M11, у которой доля рекламаций 25,70 % против 12,1 % у остальных моделей (отношение шансов 2,51). Даны рекомендации для конструкторских служб завода и сервисной сети, а также оценка экономического эффекта адресного подхода по сравнению с массовой сервисной кампанией.
